## The moat is cross-record memory, not a search

The defensible asset is not "what is true" (that is a search four funded companies already
run) but an accumulating record of what has already been proven — and, more valuably, what
has been proven *unprovable* — so each production reuses the last instead of re-paying for
it. This is a data / learning network effect: the product compounds as its record grows.

- [CLAIM] Data network effects occur when a product's value grows as it accumulates more data, which is a recognized source of long-term business defensibility. [URL: https://www.nfx.com/post/network-effects-manual]

## What shipped (repo-internal — clears against the local file, not the web)

- [CLAIM] Agent Science's cross-production log makes a claim proven or proven-unprovable on ONE subject reusable on ANOTHER with no new Parallel search, so the marginal cost of the second production falls — the compounding moat. [REPO: agent_science.py clear_script; clearance/refusal_log.py]
- [CLAIM] Same-subject reuse (corpus) and cross-subject reuse (log) are counted separately — corpus_hits vs log_hits — because they are different economic objects; folding them would overstate either. [REPO: agent_science.py]
- [CLAIM] The record is a LOG: a refusal has no offsetting credit to net out, so the store only ever grows — an append-only record, which is why the module is clearance/refusal_log.py. [REPO: clearance/refusal_log.py]
