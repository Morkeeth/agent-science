## The five signals (shared/needs.ts → deriveSignals)

`unpushed`, `dirty`, `silent` (7–30d quiet transition), `destructive` (≥10 files
deleted by commits in last 7d), `run-failed`, plus `session-no-commit` (agent
session ended, ≥5 assistant turns, no commit landed after session start — the
illusion-of-done tell). State-transition engine: items enter on transition, leave
when the world resolves them; only own bookkeeping (since/snooze/dismiss) persisted.

Ranking (`shared/loop.ts`): a deadline within `DUE_SOON_DAYS = 3` (or overdue)
outranks kind; then kind rank `unpushed(0) < run-failed(1) < destructive(2) <
dirty(3) < session-no-commit(4) < silent(5)`; ties break on age, oldest first.
`atRisk` = unpushed | dirty | run-failed | destructive.

## The evidence gate

`verify(artifact)` in `loop.ts` delegates to `classifyEvidence` (`evidence.ts`);
admits to DELIVERED only a file / URL / number-with-command-and-read-time. Otherwise
rejected with reason. `delivered.ts` `admittedEntries` feeds the "shipped this week"
count on Pulse. Outward acts (push/deploy/publish/post/release/spend) are never
performed and never clickable — rule, not stub (`planFor` carries them as REQUIRED
APPROVAL).
