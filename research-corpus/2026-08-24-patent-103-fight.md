## The examiner's strongest §103 combination

**Ref A — rule-first / ML-fallback hybrid (structural no-match fallback).**
- **US10885593 "Hybrid classification system"** (granted 2021-01-05). Rules act as a
  correcting filter over a model-based classifier; combines rule-based + statistical.
  https://patents.google.com/patent/US10885593  ·  https://patents.justia.com/patent/10885593
- **Rasa `RulePolicy` vs `TEDPolicy`** — real, dateable, documented production instance: an
  exact-match rule layer decides when a rule fires; an ML policy predicts otherwise. Clean
  structural-fallback (not a score) reference for an examiner. (dialogue-stack docs, public.)
- Hybrid ML + rule-based expert-system text categorization — established academic pattern
  (ResearchGate 221438964).

**Ref B — cost-motivated cascade to a large model.**
- **FrugalGPT** arXiv:2305.05176 — escalate only the hard tail to cut cost.
- **"When in Doubt, Summon the Titans"** arXiv:2110.10305 — route only hard inputs to the big
  model for efficient inference. Explicit cost/efficiency motivation to combine.

**Motivation to combine = cost.** "Route the inputs the deterministic rules cannot resolve
(Ref A) to the expensive LLM (Ref B) to minimize cost (Ref B's stated benefit); a rule that
fires-or-not inherently carries no score, so the 'no confidence score' feature is merely the
absence of an optional element." Credible, non-frivolous. This is why the grade is marginal.

## References probed that turned out to HELP the applicant

- **US7603267 "rules-based grammar + statistical model for NLU slots"** — *fetched full text.*
  The statistical (HMM/n-gram) and rule (CFG) components run **IN PARALLEL** via a single
  Viterbi decode over a composite model; both score simultaneously. **NOT a structural fallback
  gate** — no "if the rule can't decide, escalate" step. Cite AS APPLICANT EVIDENCE that the
  classic hybrid art *integrates by joint probability*, the opposite of a threshold-free
  structural gate. Do not let the examiner lead with it.
  https://patents.google.com/patent/US7603267B2/en
- **US5963894 / US5752052 "bootstrapping statistical processing into a rule-based parser"** —
  PDF unreadable (CCITT-fax garble); title suggests it *tracks likelihood of success per rule*,
  i.e. probabilistic, not a structural no-match trigger — which also helps (it's score-based).
  Not relied on.

## The SLEEPER reference (partially undercuts the "no score" distinction)

- **Predictor–rejector abstention** — Cortes/Mohri line; arXiv:2512.22886 (multi-class
  abstention + multi-expert deferral), JMLR reject-option work (v24/21-0048). Explicitly
  teaches rejectors that are **NOT confidence thresholds** — a learned rejector `r` that "can
  generally differ from a threshold-based function." So the art *already knows* deferral need
  not be a threshold. **Surviving distinction:** those rejectors are LEARNED functions with
  trained parameters fit on data; ANGLE 1's gate is CLOSED-FORM, zero learned parameters, no
  calibration set. This is why the memo's key amendment moves the "no calibration" negative
  onto the GATE, not just the labels.

## What survives — the applicant's spine (Branch 3 vs Branch 4, from the code)

A "no rule matched" hybrid escalates its *entire* unresolved region. ANGLE 1 does NOT: inside
the no-lexical-evidence region (disjoint object sets), it STILL answers DIFFERENT deterministically
when intents are incompatible (Branch 3), and escalates ONLY disjoint-AND-compatible (Branch 4).
It *subdivides the no-evidence region* and positively identifies the one lexically-undecidable
cell — a positive decision about where evidence runs out, not the absence of a decision. Ref A
has no mechanism to answer confidently *inside* its own fallback region. Secondary: no
calibration/learned parameter (structural, nothing to fit); unexpected result = 13/13 confident
precision with zero tuning, all errors confined to the escalated cell (24-item property, not a
theorem — secondary evidence only, drop Claim 7).

## Net

**Marginal, unchanged from the cascade-line finding — the §103 flank is real but arguable.**
Biggest killer overall is actually **§101 Alice** (compare-two-token-sets = abstract mental
process), which the earlier files did not weigh; §103 over rule-first/ML-fallback is the close
second. Both survivable only with disciplined prosecution. Provisional is cheap option value;
non-provisional survival with meaningful scope ~35–45%.
