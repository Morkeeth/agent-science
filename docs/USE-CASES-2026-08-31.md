# Use cases beyond EU Orphan Works

**Problem:** Hosted demos, aliases, and scout reel all orbit **Directive 2012/28/EU**. That is a strong *one* claim. As a product story it reads like a single-instrument tool. Judges and buyers need to see the **same engine** on different domains.

**Rule that stays fixed:** paste claims → SOURCED with verbatim span, or UNSOURCED with named cause. Locator untrusted. Verifier structural.
