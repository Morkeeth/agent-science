Compare against `docs/S1-BASELINE-2026-09-07.md`. Identical environment: pinned
`REFUSAL_LOG_DB` and `AGENT_SCIENCE_TRUTH_DB`, no provider keys, no live discovery.

Full suite: **485 passed / 66 subtests** before, **499 passed / 66 subtests** after

## What changed for the user

| journey step | before | after |
|---|---|---|
| repeat ask | `SOURCED, tier=free` | same, plus `evidence_age_days`, `source_fetched_at`, `source_sha256`, `last re-read` |
| related but different question | `candidates offered: 0` | `candidates offered: 2`, each labelled a candidate, no verdict reused |
| after a source change | identical `SOURCED` answer, silently | `recheck` re-reads, flips the claim, names dependents |
| ask again after the change | `SOURCED` | `NOT_CLEARED / prior_claim_unsettled` with the prior verdict, its cause, and what would settle it |
| re-verification command | none | `agent-science recheck`, MCP `science_recheck` |

## What this does not do
- It makes no claim about saved provider calls, money or time. No provider was called.
- A verbatim span is evidence that a document contains those words. It is not
  entailment and it is not truth. Recheck compares documents; it does not judge them.
- `changed_quote_intact` says the sentence survived, not that the surrounding document
  still means the same thing.
- A source that could not be read is `unchecked`, never `unchanged`.
- A claim written before these columns existed reports its evidence age as unknown, and
  its first recheck records a baseline rather than inventing a comparison.
- Candidate retrieval is navigation. Reuse is still exact-assertion only.
- `dependents()` sweeps the shared registry only. The personal shelf
  (`~/.agent-science/truth.db`, written by `visibility.panel`) is not swept, so a
  `personal_prior` pane can still show SOURCED beside a flipped registry claim.
- The live route was exercised once: `recheck --live` re-fetched 4 real public sources
  and reported `unchanged=4`. No provider (Parallel, Gemini) was called at any point.
- Every query count in the pinned registry is my own. Nothing here is popular.
