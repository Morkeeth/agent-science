# S1 ambition pass, 2026-09-07

Inspected at the source: `dictionary.py`, `refusal_log.py`, `stack_search.py`,
`visibility.py`, `query_analytics.py`, `instruments.py`, `cases.py`, `independence.py`,
and the `claims`/`queries`/`claim_observations` schema.

## A. Evidence freshness and change-triggered re-verification on the websearch path
Pain: a SOURCED answer is replayed from `claims` with no age and no proof the source
still says it. `record()`'s UPDATE branch overwrites `first_seen_at` with the write
time, so it dates the row, not the evidence. No column holds the snapshot hash or fetch
time, and nothing re-reads the cited URL.
Recurring value: reuse stays honest, and a changed source names every dependent answer
rather than replaying it.
Why a judge remembers it: the demo shows a stale answer being caught by the product.
Missing today: `cases.refresh` does source-change to dependent-decision flagging for
research cases only. The registry that the ordinary websearch/CLI/MCP path reads has no
equivalent. Journey steps one and two half exist; step three is absent.

## B. Source authority and independence on the lookup result
Pain: `_verdict_to_stack` returns a URL and a span. Authority and independence are not
on the result. `independence.py` and `source_metadata.py` exist but the websearch path
does not read them.
Recurring value: a reader can weigh a single citation.
Why not chosen: it improves one pane of an answer. It does not make reuse safe, and it
does not close the journey. Judged second.

## C. Near-duplicate reuse (paraphrase matched to a stored verdict)
Pain: the same question phrased differently misses the registry and pays again.
Why rejected, not deferred: `refusal_log.claim_key` and its own comment forbid it:
"no heuristic slot can authorize assertion reuse". Reusing a verdict across a wording
variant is the product asserting something it never judged. The honest version of C is
aliasing for retrieval only, which already exists.

## Chosen: A
It is the only one of the three that delivers the whole cold, repeat, changed-evidence
journey rather than a component, and it matches the S1 contract: ask once, reuse while
valid, refresh the changed parts.

## Limits declared up front
No provider keys are set in this environment, so live Parallel/Gemini discovery is
unavailable. The path built is the local one: real public sources fetched over the
network, real verbatim spans, real hashes. No claim about saved provider calls, money or
time is made anywhere in this slice. The worktree registry starts empty, so every query
count in it is my own; nothing here is "popular".
