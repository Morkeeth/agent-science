# Agentic practices — seed claims for Agent Science
# Origin: aistrava/docs/PRACTICES-CORPUS.md (Agent Grinder)
# Discipline: each URL is the named primary; verify before treating as SOURCED.

[CLAIM] Andrej Karpathy documented that a CLAUDE.md rules file cut agent mistakes from about 41 percent to 11 percent.
[URL] https://aibuilderclub.com/blog/karpathy-claude-md-rules

[CLAIM] Simon Willison describes an explore, plan, code, commit loop as an agentic engineering pattern.
[URL] https://simonwillison.net/2026/Feb/23/agentic-engineering-patterns

[CLAIM] Geoffrey Huntley's Ralph loop uses a fresh agent, clean context, one unit of work, then commit and exit.
[URL] https://linearb.io/blog/ralph-loop-agentic-engineering-geoffrey-huntley

[CLAIM] Thorsten Ball defines an agent as an LLM, a loop, and enough tokens, and stresses making the check real and defining when to stop.
[URL] https://ampcode.com/how-to-build-an-agent

[CLAIM] Addy Osmani writes about self-improving agents whose rules and memory evolve from mistakes.
[URL] https://addyosmani.com/blog/self-improving-agents

[CLAIM] Anthropic's engineering post on effective context engineering for AI agents treats context as the key resource and recommends clearing between tasks, planning, CLAUDE.md, and TDD.
[URL] https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents

[CLAIM] Mitchell Hashimoto describes always having an agent running — if he is coding an agent is planning, if they are coding he is reviewing — and saving research to a spec first.
[URL] https://newsletter.pragmaticengineer.com/p/mitchell-hashimoto

[CLAIM] The arXiv paper Professional Developers Don't Vibe, They Control argues that professional developers control agentic coding rather than vibe coding.
[URL] https://arxiv.org/abs/2512.14012

[CLAIM] The arXiv paper Agentic Software Engineering: Foundational Pillars discusses foundational pillars of agentic software engineering.
[URL] https://arxiv.org/abs/2509.06216

[CLAIM] CodeScene argues that agentic coding needs more rigor, structure, and quality — not less.
[URL] https://codescene.com/blog/agentic-ai-coding-best-practice-patterns
